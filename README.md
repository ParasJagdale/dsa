# Data Structures and Algorithms (DSA)

A comprehensive collection of Data Structures and Algorithms implementations in C++ and Python.

## 📚 Contents

### Hash Tables
- **1linearprobing.py** - Linear Probing hash table implementation in Python
- **2Doublehashing.cpp** - Double Hashing collision resolution technique in C++

### Set Operations
- **3setADT.py** - Set Abstract Data Type implementation with basic operations in Python

### Binary Search Trees (BST)
- **4bst(1).cpp** - Basic Binary Search Tree implementation in C++
- **5bst(2).cpp** - Alternative BST implementation in C++
- **6expressiontree.cpp** - Expression Tree implementation in C++
- **7bstdict(1).cpp** - Dictionary using BST (version 1) in C++
- **8bstdict(2).cpp** - Dictionary using BST (version 2) in C++
- **dictionaryBST.cpp** - Dictionary implementation using Binary Search Tree in C++

### Graphs
- **9graphadjlist.cpp** - Graph implementation using Adjacency List in C++
- **10graphadjmat.cpp** - Graph implementation using Adjacency Matrix in C++
- **11MSTgrapgcities.cpp** - Minimum Spanning Tree for cities graph in C++

### Advanced Trees
- **12OBST.cpp** - Optimal Binary Search Tree implementation in C++
- **13AVLtree1.cpp** - AVL Tree (self-balancing BST) implementation (version 1) in C++
- **14AVLtree2.cpp** - AVL Tree implementation (version 2) in C++

### Other Data Structures
- **15priorityqueue.cpp** - Priority Queue implementation in C++
- **16sequentialfilestudent.cpp** - Sequential File organization for student records in C++
- **17indexsequentialemployee.cpp** - Indexed Sequential File organization for employee records in C++

## 🛠️ Technologies Used

- **C++** - Main language for most implementations
- **Python** - Used for hash tables and set operations

## 🚀 How to Run

### C++ Programs

1. Compile the C++ file:
```bash
g++ filename.cpp -o output
```

2. Run the executable:
```bash
./output
```

Example:
```bash
g++ 13AVLtree1.cpp -o avltree
./avltree
```

### Python Programs

Run the Python file directly:
```bash
python3 filename.py
```

Example:
```bash
python3 1linearprobing.py
```
